# Changelog

## 0.2.2 — 2026-10-14
- Removed source, test files, build scripts and build logs from the Thunderstore install ZIP, as requested by moderation.
- Prepared complete source as a separate GPL-3.0 archive.
- No changes to the 0.2.1 panel, brightness, mist or synchronization behavior.

## 0.2.1 — 2026-10-14
- Replaced low-contrast helper text with bright white text and dark outlines.
- Lightened blue headings and increased helper text size.
- Kept read-only labels readable while leaving controls locked.
- Preserved the wooden panel, brightness behavior and v2 sync protocol.

## 0.2.0 — 2026-10-14
- Integrated gamma-style ambient brightness into the existing F8 controls.
- Added Natural, Soft (35%) and Clear (60%) brightness presets and a 0–100% slider.
- Synced brightness settings with the same server-admin authorization and persistence as mist controls.
- Added an inventory-style wooden panel, Rusty Heathens emblem and electric-blue selection highlights.
- Preserved mist settings, plugin identity, F8 and Shift+F8 shortcuts.
- Added color/alpha preservation, zero-input protection and lighting restoration.
- Updated the sync protocol; server and clients must all use 0.2.0.
- Prevented simultaneous loading with the standalone ColdSpirit.GammaMod.
- Included GPL-3.0 license, attribution, full source and build/test instructions.
- Compilation and automated tests passed; in-game validation remains pending.

## 0.1.0
- Initial Mistlands visibility and wisplight/torch range controls.
